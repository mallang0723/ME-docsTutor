# Marinara Docs Tutor 로어북 확장

*[English guide here](./README.en.md)*

Marinara Engine에 들어 있는 **공식 문서(docs)를 읽어 초보자용 지식 로어북을
자동 생성**하고, 선택한 캐릭터에 장착해 주는 확장입니다.

장착된 캐릭터는 채팅 중에 마리나라 기능에 대한 질문("로어북이 뭐야?",
"프리셋은 어떻게 써?")에 문서 기반으로 답할 수 있게 됩니다.

- 문서 원본은 **수정하지 않습니다**
- 재실행하면 로어북 **항목만 갱신**됩니다 (중복 생성 없음)
- 이 확장이 만들지 않은 로어북은 **절대 건드리지 않습니다**

## 요구 사항

- **Marinara Engine 개발 버전(2.3.5, staging)** — 정식 2.3.4에서는 동작하지
  않습니다. 개발 버전 전환 방법은 별도 안내글을 참고하세요.

## 설치 (안전장치 4단계)

확장은 프로그램 안에서 실행되는 코드라서, 마리나라는 일부러 여러 단계를
거치게 만들어 뒀습니다. 순서대로 하면 됩니다.

### ① `.env` 에 한 줄 추가

마리나라를 완전히 종료한 뒤, **설치 폴더**에서 명령창(PowerShell/터미널)을
열고 아래 한 줄을 실행하세요.

윈도우 (탐색기로 설치 폴더 열기 → 주소창에 `powershell` 입력 → 엔터):

```powershell
Add-Content .env -Value "", "ENABLE_EXTERNAL_EXTENSIONS=true"
```

macOS / Linux / Termux (설치 폴더에서):

```sh
echo "ENABLE_EXTERNAL_EXTENSIONS=true" >> .env
```

그다음 마리나라를 다시 켜세요.
> **🐳 도커로 쓰시는 경우** — `.env` 대신 `docker-compose.yml` 파일을 엽니다.
> `environment:` 줄을 찾아 그 **아래에 한 줄만** 추가하세요 (다른 줄과 앞 칸을 맞춰서):
>
> ```yaml
>       - ENABLE_EXTERNAL_EXTENSIONS=true
> ```
>
> 저장한 뒤 `docker compose up -d` 를 실행하면 적용됩니다.
> 다른 기기 브라우저로 접속해 쓰신다면 같은 자리에
> `- ADMIN_SECRET=원하는비밀값` 도 한 줄 추가하세요 (위험 구역을 열 때 필요).
> 적용됐는지 확인하려면:
>
> ```sh
> docker compose exec marinara env | grep ENABLE_EXTERNAL
> ```
>
> 값이 나오면 적용된 것이고, 안 나오면 `docker compose up -d` 를 한 번 더 실행하세요.


### ② 앱에서 확장 허용 켜기

**Settings**(설정) → **Advanced**(고급) → **Danger Zone**(위험 구역) →
**Allow third-party extension imports**(서드파티 확장 가져오기 허용)를 켭니다.

### ③ 확장 가져오기

먼저 [**Releases 페이지**](../../releases/latest)에서
`marinara-docs-tutor.zip` 을 내려받으세요 (압축을 풀 필요 없습니다).

**Settings** → **Addons**(애드온) → **External Extensions**(외부 확장)에서
**가져오기** 버튼으로 방금 받은 **zip 파일을 그대로** 선택합니다.

### ④ 승인하고 켜기 — 여기까지 해야 동작합니다

목록에 나타난 확장의 **전원 아이콘**을 누르면 승인 창이 뜹니다.

> 이 확장은 화면에 버튼을 그려야 해서 **"전체 페이지 접근"** 승인 창이
> 뜹니다. 이 권한은 확장이 마리나라 화면 전체를 읽고 바꿀 수 있다는
> 뜻입니다 — 그래서 마리나라가 일부러 무섭게 경고합니다. 코드를 신뢰할 때만
> **"이 코드 그대로 실행"**을 누르세요.

확장 파일이 갱신되면(업데이트 등) 같은 승인 창이 다시 뜹니다. 정상입니다 —
바뀐 코드는 다시 승인해야 실행되는 안전장치입니다.

## 사용법

1. 화면에 나타난 **📚 버튼**을 누릅니다 (드래그로 위치 이동 가능, 위치는 기억됩니다)
2. 로어북을 장착할 **캐릭터를 선택**합니다
3. **"로어북 생성 + 장착"**을 누르고 완료 메시지를 기다립니다

마리나라를 업데이트한 뒤 다시 실행하면 로어북이 최신 문서 기준으로 갱신됩니다.

## 문제 해결

| 증상 | 대처 |
|---|---|
| 가져오기 메뉴가 안 보임 | ①·② 단계 확인 후 마리나라 재시작 |
| 승인했는데 📚 버튼이 안 뜸 | 페이지 새로고침. 그래도 안 되면 브라우저 콘솔(F12)의 빨간 오류를 알려주세요 |
| "docs를 읽지 못했습니다" | 마리나라 버전이 오래됐거나 문서 구조가 바뀐 경우입니다. 확장 업데이트를 확인하세요 |
| "이미 있지만 확인할 수 없어 건드리지 않습니다" | 같은 이름의 로어북을 직접 만드신 경우입니다. 그 로어북의 이름을 바꾸거나 삭제한 뒤 재실행하세요 |
| 실행 도중 확장을 꺼서 멈춤 | 이미 완료된 변경은 되돌려지지 않습니다. 다시 켜고 재실행하면 정리됩니다 |

## 알아두실 것

- 이 확장은 여러분의 마리나라 서버(같은 컴퓨터)하고만 통신합니다. 외부로
  데이터를 보내지 않습니다.
- 소스는 전부 이 저장소에 공개돼 있습니다. 승인 창의 해시는 이 코드
  그대로인지 확인하는 장치입니다.
